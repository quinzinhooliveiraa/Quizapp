# Dar mais destaque ao "Jogar Online" (banner no Todos + card grande no Meu Espaço)

**Objetivo:** hoje o CTA "Uma sala pra vocês, mesmo de longe" fica escondido no meio do Meu Espaço. Vamos: (a) colocar um **banner no topo da aba "Todos"** (primeira que a pessoa vê) e (b) aumentar o destaque no Meu Espaço.

**IMPORTANTE: aplicar direto nos arquivos. NÃO SALVE COMO ASSET.**

## Fix — `artifacts/perguntas-de-conexao/src/App.tsx`

### 1. Adicionar banner no topo da aba "Todos"

Achar onde renderiza o conteúdo da aba "Todos" (`activeNav === 'todos'`). Vai ter algo tipo:

```tsx
{activeNav === 'todos' && (
  <>
    <section className="today-hero">...</section>
    ...
  </>
)}
```

Adicionar ANTES do `<section className="today-hero">` (ou no topo do bloco todos):

```tsx
{isOwner && (
  <button
    type="button"
    onClick={() => setLocation('/play')}
    className="play-banner-cta"
    data-testid="button-play-online-top"
  >
    <div className="play-banner-glow" aria-hidden="true" />
    <div className="play-banner-icon">
      <Wifi size={20} />
    </div>
    <div className="play-banner-text">
      <p className="play-banner-kicker">jogar online</p>
      <strong>Uma sala pra vocês, mesmo de longe</strong>
      <small>Crie uma sala em segundos e mande o código pra qualquer pessoa</small>
    </div>
    <ArrowRight size={20} className="play-banner-arrow" />
  </button>
)}
```

Se estiver usando `wouter`, `setLocation` já é o `useLocation()[1]`. Se não, usar `window.location.assign('/play')`.

**Adicionar imports** no topo (com os outros de lucide-react):
```tsx
import { ..., Wifi } from 'lucide-react';
```

### 2. Aumentar destaque do card no Meu Espaço

Achar o card atual do "jogar online" no Meu Espaço (procurar por `Uma sala para vocês` ou `link-play-online`). Está algo tipo:

```tsx
<Link href="/play" className="eu-play-card">
  <span><Wifi size={...} /></span>
  <div>
    <p>JOGAR ONLINE</p>
    <p>Uma sala para vocês, mesmo de longe.</p>
    <p>criar ou entrar com código →</p>
  </div>
</Link>
```

Substituir por (card grande, chamativo, altura dobrada):

```tsx
{isOwner && (
  <Link href="/play" className="eu-play-hero" data-testid="link-play-online">
    <div className="eu-play-hero-glow" aria-hidden="true" />
    <div className="eu-play-hero-content">
      <div className="eu-play-hero-icon"><Wifi size={26} /></div>
      <div>
        <p className="eu-kicker">jogar online</p>
        <h2>Uma sala pra vocês,<br /><em>mesmo de longe.</em></h2>
        <p className="eu-play-hero-note">Crie uma sala, mande o código, e joguem juntos em tempo real de qualquer lugar.</p>
        <span className="eu-play-hero-cta">Criar ou entrar com código <ArrowRight size={16} /></span>
      </div>
    </div>
  </Link>
)}
```

# Ajustes: editar tipo de relacionamento e pronome

**Contexto:** no menu de Ajustes (⚙️) hoje só dá pra editar o nome. Precisa também editar o tipo de relacionamento e o pronome do parceiro (o que a pessoa escolheu no onboarding). Isso afeta o peso das perguntas (Parte B) — se a pessoa mudou de "saindo com alguém" pra "esposa", faz sentido as perguntas mudarem.

Por enquanto salva só no localStorage (mesma abordagem do onboarding). Sincronização com servidor pra funcionar em outros aparelhos vira um refactor futuro.

**IMPORTANTE: aplicar direto nos arquivos. Não é pra salvar como asset.**

## Fix — `artifacts/perguntas-de-conexao/src/App.tsx`

### 1. Adicionar constante com as opções (topo do arquivo, junto de outras constantes)

Procurar onde ficam as constantes globais (perto de `PERSONALIZED_DECKS_STORAGE_KEY`, linha ~53) e adicionar:

```tsx
const RELATIONSHIP_OPTIONS = [
  'Meu namorado ou minha namorada',
  'Meu esposo ou minha esposa',
  'Alguém com quem estou saindo',
  'Namoro à distância',
];
const PRONOUN_OPTIONS = ['Ela', 'Ele', 'Prefiro não dizer'];
```

### 2. Dentro do `AppExperienceReference`, adicionar state e handler

Perto de outros useState (por exemplo perto de `const [settingsOpen, setSettingsOpen]`), adicionar:

```tsx
const [editRelationship, setEditRelationship] = useState(() => safeGetItem('conexao-relationship') || '');
const [editPronoun, setEditPronoun] = useState(() => safeGetItem('conexao-partner-pronoun') || '');
useEffect(() => {
  if (settingsOpen) {
    setEditRelationship(safeGetItem('conexao-relationship') || '');
    setEditPronoun(safeGetItem('conexao-partner-pronoun') || '');
  }
}, [settingsOpen]);

const savePreferences = () => {
  if (editRelationship) safeSetItem('conexao-relationship', editRelationship);
  if (editPronoun) safeSetItem('conexao-partner-pronoun', editPronoun);
  setSettingsOpen(false);
};
```

### 3. Atualizar o modal de Ajustes com as novas opções

Achar o modal de settings (perto da linha 1617, começa com `{settingsOpen && <div className="app-modal-backdrop">`):

Antes do botão "Editar como te chamar", adicionar essas seções:

```tsx
<div className="settings-editable">
  <label className="settings-label">Tipo de relacionamento</label>
  <div className="settings-choices">
    {RELATIONSHIP_OPTIONS.map(opt => (
      <button
        key={opt}
        type="button"
        onClick={() => setEditRelationship(opt)}
        className={`settings-choice ${editRelationship === opt ? 'is-selected' : ''}`}
        data-testid={`button-relationship-${opt}`}
      >
        {opt}
      </button>
    ))}
  </div>
</div>

<div className="settings-editable">
  <label className="settings-label">Pronome do parceiro</label>
  <div className="settings-choices">
    {PRONOUN_OPTIONS.map(opt => (
      <button
        key={opt}
        type="button"
        onClick={() => setEditPronoun(opt)}
        className={`settings-choice ${editPronoun === opt ? 'is-selected' : ''}`}
        data-testid={`button-pronoun-${opt}`}
      >
        {opt}
      </button>
    ))}
  </div>
</div>

<button
  onClick={savePreferences}
  className="app-primary-button"
  data-testid="button-save-preferences"
>
  Salvar preferências
</button>
```

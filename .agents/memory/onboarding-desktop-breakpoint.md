---
name: Onboarding desktop breakpoint
description: The onboarding side rail needs wide-screen space and should not compete with the main flow on medium desktop widths.
---

The onboarding rail is a wide-desktop enhancement, not a universal PC layout. Medium desktop widths should use the full-width onboarding frame without the rail so the intro artwork, copy, and primary action remain visible.

**Why:** The rail contains long editorial copy and stage labels; when it is shown around laptop-width, its grid column becomes too narrow and the content wraps into overlapping vertical fragments.

**How to apply:** Treat 1180px as the minimum width for the onboarding rail unless the rail copy is redesigned. Keep mobile and medium desktop flows on the shared full-width frame.

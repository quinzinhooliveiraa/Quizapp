==================================================
1. LP3 NO TRACKING
==================================================

Arquivo provável:
artifacts/perguntas-de-conexao/src/pages/Lp3.tsx

Faça a LP3 utilizar o MESMO mecanismo de tracking já utilizado por v1/v2.

Não crie um segundo sistema de tracking.

Se existir um hook compartilhado como:

IMPORTANTE:
Os eventos específicos da experiência LP3 podem continuar existindo no frontend, mas os eventos importantes para analytics precisam chegar ao backend através do mecanismo existente.

==================================================
2. MICROSOFT CLARITY
==================================================

A LP3 deve inicializar o MESMO Clarity usado pelas outras landing pages.

Não crie outro projeto Clarity.
Não altere o ID existente.
Não duplique o script.

A LP3 precisa:

- gerar/recuperar o mesmo visitorKey usado pelo sistema;
- identificar o visitante no Clarity;
- capturar clarityUserId;
- capturar claritySessionId;
- enviar esses identificadores ao backend da mesma maneira que v1/v2.

Objetivo:

Quando eu entrar no Admin → LP3 → Sessões → Ver gravação,

deve ser possível encontrar a gravação correspondente no Clarity quando ela existir.

# "Destravar": dica quando dá branco na pergunta

Às vezes a pessoa lê uma pergunta e trava — não sabe o que responder, se sente cobrada, ou fica pensando "qual seria a resposta certa". Um botão pequeno, discreto, escondido por padrão. Só aparece se a pessoa tocar. Ajuda o **COMO** responder (jamais o **QUÊ** — nunca dá exemplo de resposta).

## Em `artifacts/perguntas-de-conexao/src/App.tsx`

### 1. Adicionar estado no componente `AppExperienceReference` (perto de onde tem `writingOpen`)

Achar (perto da linha 1289):

```tsx

```

Adicionar logo antes ou depois:

```tsx
const [unstuckOpen, setUnstuckOpen] = useState(false);
useEffect(() => { setUnstuckOpen(false); }, [currentQuestion?.id]);
```

(Fecha automaticamente quando muda de pergunta.)

### 2. Adicionar o botão + painel dentro do `question-card-front`

Adicionar logo depois (antes do `{writingOpen && ...}`):

```tsx
<div className="question-unstuck">
  {unstuckOpen ? (

      <p className="question-unstuck-title">Sem pressa. Se ajudar:</p>
      <ul>
        <li>Responde a primeira coisa que veio à cabeça — sem editar.</li>
        <li>Reformula a pergunta com suas próprias palavras.</li>
        <li>Pega só um pedacinho: uma cena, uma sensação, uma palavra.</li>
      </ul>
      <button
        type="button"
        className="question-unstuck-close"
        onClick={() => setUnstuckOpen(false)}
        data-testid="button-close-unstuck"
      >Fechar</button>
    </div>
  ) : (
    <button
      type="button"
      className="question-unstuck-trigger"
      onClick={() => setUnstuckOpen(true)}
      data-testid="button-open-unstuck"
    >Travou?</button>
  )}
</div>
```

## Regra fundamental (não pode quebrar)
As dicas ajudam **como responder**, nunca **o que responder**. Nunca dar exemplo de resposta, sugerir tema específico, ou fazer perguntas mais fáceis no lugar. Se em algum momento futuro alguém pedir pra "colocar exemplos", tem que dizer não — quebra o produto.

## Verificação
- Abre uma pergunta → embaixo aparece um texto pequeno cinza "Travou?"
- Toca → substitui pelo painel com as 3 dicas
- Passa pra próxima pergunta → o painel some sozinho, volta o "Travou?"
- Toca em "Fechar" → volta o "Travou?" sem trocar de pergunta

# Landing page de vendas nova — Perguntas de Conexão

**Objetivo:** substituir a landing atual (que hoje é só um hero + pacotes bem simples) por uma landing dedicada de vendas, otimizada pra tráfego pago do Facebook. Estrutura híbrida com mini-quiz interativo pra criar engajamento sem afastar tráfego.

**Estratégia (importante entender):** fluxo continua o mesmo (paga → onboarding → app). A landing tem um mini-quiz de 3 telas que dá "gostinho" de personalização e mostra 3 perguntas de verdade, depois CTA de compra. NÃO é pra fazer onboarding grátis antes de pagar.

**Referências que inspiraram**: How Deep Will You Go (US), We're Not Really Strangers, Segredo do Relacionamento, Casados e Felizes.

## 2. Adicionar componente `LandingQuiz` no MESMO arquivo `App.tsx`

No topo do arquivo (perto de outros componentes internos), adicionar:

```tsx
function LandingQuiz({ onFinish }: { onFinish: () => void }) {
  const [step, setStep] = useState(0);
  const [role, setRole] = useState<'namorando' | 'casado' | 'longa' | ''>('');
  const [phase, setPhase] = useState<'inicio' | 'anos' | 'reconectar' | ''>('');
  const [theme, setTheme] = useState<'porto' | 'faisca' | 'livro' | ''>('');

  const PREVIEWS: Record<string, { title: string; questions: string[] }> = {
    porto: {
      title: 'Porto Seguro',
      questions: [
        'Qual foi a última vez que você se sentiu completamente em casa comigo?',
        'O que eu faço, sem perceber, que te faz respirar mais fundo?',
        'Se um dia esta versão nossa acabasse, do que você mais sentiria falta?',
      ],
    },
    faisca: {
      title: 'Faísca',
      questions: [
        'O que em mim ainda te surpreende — que você não esperava?',
        'Quando foi a última vez que você me olhou e pensou "quero de novo"?',
        'Qual gesto meu, mesmo bobo, te desarma na hora?',
      ],
    },
    livro: {
      title: 'Livro Aberto',
      questions: [
        'Qual medo você tem sobre nós que ainda não me disse?',
        'O que você acha que eu deveria saber sobre você e nunca perguntei?',
        'Existe algo que você mudaria na gente hoje, se pudesse?',
      ],
    },
  };

  if (step === 3) {
    const preview = PREVIEWS[theme] || PREVIEWS.porto;
    return (
      <div className="lp-quiz-result">
        <p className="lp-quiz-pill">Seu baralho ideal pra começar:</p>
        <h3 className="lp-quiz-result-title">{preview.title}</h3>
        <div className="lp-quiz-cards">
          {preview.questions.map((q, i) => (
            <div key={i} className="lp-quiz-preview-card">
              <span className="lp-mock-tag">{preview.title.toLowerCase()}</span>
              <p>"{q}"</p>
              <span className="lp-mock-num">{String(i + 1).padStart(2, '0')} / {preview.questions.length}+</span>
            </div>
          ))}
        </div>
        <p className="lp-quiz-cta-text">
          <strong>Essas são 3 de {preview.title === 'Porto Seguro' ? '31' : preview.title === 'Faísca' ? '31' : '31'}.</strong> Destrave as outras + os outros 14 baralhos:
        </p>
        <button onClick={onFinish} className="lp-cta-primary lp-cta-big" data-testid="button-quiz-cta">
          Ver o preço <ArrowRight size={18} />
        </button>
      </div>
    );
  }

  const stepConfig = [
    { key: 'role', label: 'Vocês estão:', options: [{ v: 'namorando', l: 'Namorando' }, { v: 'casado', l: 'Casados' }, { v: 'longa', l: 'Relação longa' }], set: (v: string) => { setRole(v as typeof role); setStep(1); } },
    { key: 'phase', label: 'Como você descreveria a fase de vocês?', options: [{ v: 'inicio', l: 'Início, descobrindo' }, { v: 'anos', l: 'Anos juntos, rotina' }, { v: 'reconectar', l: 'Precisamos reconectar' }], set: (v: string) => { setPhase(v as typeof phase); setStep(2); } },
    { key: 'theme', label: 'O que mais te chama agora?', options: [{ v: 'porto', l: 'Aquecer, sem susto' }, { v: 'faisca', l: 'Provocar, apimentar' }, { v: 'livro', l: 'Ir fundo de verdade' }], set: (v: string) => { setTheme(v as typeof theme); setStep(3); } },
  ][step];

  return (
    <div className="lp-quiz">
      <div className="lp-quiz-progress">
        <span className={step >= 0 ? 'is-active' : ''} />
        <span className={step >= 1 ? 'is-active' : ''} />
        <span className={step >= 2 ? 'is-active' : ''} />
      </div>
      <p className="lp-quiz-question">{stepConfig.label}</p>
      <div className="lp-quiz-options">
        {stepConfig.options.map(opt => (
          <button
            key={opt.v}
            onClick={() => stepConfig.set(opt.v)}
            className="lp-quiz-option"
            data-testid={`button-quiz-${stepConfig.key}-${opt.v}`}
          >
            {opt.l}
          </button>
        ))}
      </div>
    </div>
  );
}
```

# Fix crítico: aceitar convite não limpa sessão do dono + Onboarding usa role certo

**Bug:** admin logado clica no link do convite → aceitar → cai direto no /app pulando onboarding. Motivo: `acceptInvite` adiciona guest-token mas mantém `conexao-session` do admin. O Onboarding vê que o admin já completou (via sessionQuery), fica confuso, e redireciona pro /app.

**IMPORTANTE: aplicar direto nos arquivos. Não é pra salvar como asset.**

## Fix 1 — `artifacts/perguntas-de-conexao/src/App.tsx` — acceptInvite limpa sessão anterior

Achar (perto da linha 1626):

```tsx
const acceptInvite = () => {
  if (invite && token) {
    safeSetItem('conexao-guest-token', token);
    safeSetItem('conexao-guest-name', invite.guestName);
    safeSetItem('conexao-name', invite.guestName);
    safeSetItem('conexao-role', 'guest');
    fetch(apiUrl(`/api/access/invites/${encodeURIComponent(token)}/accept`), { method: 'POST' }).catch(() => {});
  }
};
```

Trocar por (limpa completamente qualquer resíduo de sessão anterior — dono ou onboarding pela metade):


## Fix 3 — Aplicar a mesma lógica de role no `StoredAccessGate` do App.tsx

Achar (perto da linha 405-418, o useEffect no StoredAccessGate):

```tsx
useEffect(() => {
  const wantsToBuy = typeof window !== 'undefined' && (window.location.hash === '#pacotes' || new URLSearchParams(window.location.search).get('comprar') === '1');
  if (wantsToBuy) return;
  const ownerReady = sessionQuery.isSuccess && sessionQuery.data.accessGranted;

    || (guestQuery.data as { onboardingComplete?: boolean } | undefined)?.onboardingComplete,

}, [guestQuery.data, guestQuery.isSuccess, navigate, sessionQuery.data, sessionQuery.isSuccess]);
```

Trocar por (mesma lógica: checa o role atual pra decidir):


## Sobre "a outra aba deslogou automaticamente"
Isso é comportamento **esperado** do localStorage — abas do mesmo navegador compartilham. Se você aceita convite numa aba, todas as outras abas viram convidado também. **1 navegador = 1 identidade.** Pra manter admin em uma aba e convidado em outra: usa janelas anônimas ou navegadores diferentes.

# Loading no checkout usando a animação do baralho (não um spinner novo)

**Isso substitui o prompt anterior** (`loading-checkout-replit.md` que eu mandei antes, com um spinner girando). Se você já aplicou aquele, sem problema — esse prompt aqui troca pro visual certo. Se ainda não aplicou o anterior, ignore ele e aplique só este.

**Problema:** ao clicar em "Continuar para pagamento", a chamada pra Abacate Pay pode levar alguns segundos, e hoje não tem nenhum feedback visual claro — parece que travou.

**Solução:** reaproveitar a mesma animação que já existe pra tela de "preparando seu baralho" (o baralho de cartas girando, que hoje só aparece DEPOIS de voltar do pagamento) — só que com um texto adaptado, já que nesse momento a gente está gerando o link de pagamento, não confirmando que ele foi pago.

**IMPORTANTE: aplicar direto nos arquivos. NÃO SALVE COMO ASSET.**

## 2. Estado de "demorando mais que o normal" — dentro do componente `Home`

Achar, perto dos outros `useState` do `Home`:

```tsx
const [confirmingLong, setConfirmingLong] = useState(false);
```

Adicionar logo abaixo:

```tsx
const [sendingLong, setSendingLong] = useState(false);
```

Achar o `useEffect` que cuida do `confirmingLong`:

```tsx
useEffect(() => {
    if (checkoutState !== 'confirming') {
      setConfirmingLong(false);
      return;
    }

    const timer = window.setTimeout(() => setConfirmingLong(true), 15000);
    return () => window.clearTimeout(timer);
  }, [checkoutState]);
```

Adicionar logo abaixo um equivalente pro `sending` (limite mais curto — é só a criação da cobrança Pix, não a confirmação do pagamento):

```tsx
useEffect(() => {
    if (checkoutState !== 'sending') {
      setSendingLong(false);
      return;
    }

    const timer = window.setTimeout(() => setSendingLong(true), 4000);
    return () => window.clearTimeout(timer);
  }, [checkoutState]);
```

## Verificação

1. Clicar em "Continuar para pagamento" → a tela do modal troca imediatamente pra animação do baralho girando, com "preparando seu pagamento" e "Gerando seu link de pagamento seguro."
2. Se demorar mais de 4 segundos, o texto muda pra "Só mais um instante… o link tá quase pronto." — mesma lógica que já existe na tela de confirmação pós-pagamento.
3. Assim que o link é gerado, redireciona normalmente pra Abacate Pay (comportamento não muda, só o visual da espera).
4. Testar com internet lenta (Slow 3G no DevTools) pra confirmar que a animação aparece direitinho e não trava a tela.

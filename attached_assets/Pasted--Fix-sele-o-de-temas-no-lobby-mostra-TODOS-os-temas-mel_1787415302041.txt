# Fix seleção de temas no lobby (mostra TODOS os temas + melhor contraste)

**Bug real encontrado no código:** hoje o lobby de "jogar online" tem `.slice(0, 8)` na lista de temas — só mostra 8 dos 9 temas "tema" E esconde TODOS os 6 "vibes" (Faísca, Luzes Baixas, Fogo Alto, Sem Freio, Mesmo Longe, Perto de Novo). Fix: mostrar todos + separar por categoria + melhorar contraste visual.

**IMPORTANTE: aplicar direto nos arquivos. NÃO SALVE COMO ASSET.**

## Fix — `artifacts/perguntas-de-conexao/src/pages/Play.tsx`

### 1. Achar a seção do lobby que mostra os temas (~linha 152)

Está assim (linha longa):
```tsx
{isHost ? <div className="theme-choice-grid" data-testid="list-lobby-themes">{themes.filter(theme => theme.kind === 'tema').slice(0, 8).map((theme, index) => <button ...>...</button>)}</div> : <div className="waiting-theme">...</div>}
```

### 2. Substituir o bloco do host (a parte do `isHost ? ... :`) por (mostra TEMAS agrupados + VIBES separados, sem slice):

```tsx
{isHost ? (
  <div className="theme-choice-wrap" data-testid="list-lobby-themes">
    <div className="theme-group">
      <p className="theme-group-label">Temas do dia a dia</p>
      <div className="theme-choice-grid">
        {themes.filter(theme => theme.kind === 'tema').map((theme) => (
          <button
            key={theme.id}
            className={`theme-choice ${themeId === theme.id ? 'is-selected' : ''}`}
            onClick={() => chooseTheme(theme.id)}
            data-testid={`button-lobby-theme-${theme.id}`}
          >
            <span className="theme-choice-title">{theme.title}</span>
            <small>{theme.description}</small>
            <i>{theme.count} cartas</i>
            {themeId === theme.id && <div className="theme-choice-check"><Check size={14} /></div>}
          </button>
        ))}
      </div>
    </div>

    {themes.some(t => t.kind === 'vibe') && (
      <div className="theme-group theme-group-vibes">
        <p className="theme-group-label">Vibes <span className="theme-group-badge">18+</span></p>
        <div className="theme-choice-grid">
          {themes.filter(theme => theme.kind === 'vibe').map((theme) => (
            <button
              key={theme.id}
              className={`theme-choice theme-choice-vibe ${themeId === theme.id ? 'is-selected' : ''}`}
              onClick={() => chooseTheme(theme.id)}
              data-testid={`button-lobby-theme-${theme.id}`}
            >
              <span className="theme-choice-title">{theme.title}</span>
              <small>{theme.description}</small>
              <i>{theme.count} cartas · {theme.audience}</i>
              {themeId === theme.id && <div className="theme-choice-check"><Check size={14} /></div>}
            </button>
          ))}
        </div>
      </div>
    )}
  </div>
) : (
  <div className="waiting-theme" data-testid="status-waiting-theme">
    <span><LoaderCircle size={22} className="play-spin" /></span>
    <p>A escolha do tema está<br /><strong>nas mãos de {players.find(player => player.id === hostId)?.name || 'quem criou a sala'}.</strong></p>
  </div>
)}
```

**Nota:** removi as classes `theme-choice-0`, `theme-choice-1`, etc. (que geravam 5 variações de cor confusas). Agora TODOS os cards de tema têm o mesmo look base + os vibes têm um look distinto (rosa/quente).

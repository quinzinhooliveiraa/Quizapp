# Fix: endpoint correto de consulta na Abacate Pay + log do webhook

**Diagnóstico:** O webhook chegou 3x, todas retornaram 401. O fallback (que ia consultar a Abacate direto se HMAC falhasse) tava chamando o endpoint errado: `/billings/{id}`. O endpoint certo, segundo a doc oficial da Abacate, é **`GET /checkouts/get?id=...`**. Como o fallback dava 404, `paymentConfirmed` ficava false, e o webhook retornava 401.

Também vou adicionar um log detalhado que grava o payload real do webhook — assim se der outro erro depois, eu tenho o que preciso pra depurar sem chutar.

## 1. `artifacts/api-server/src/lib/abacatepay.ts`

Achar a função `fetchAbacateBillingStatus` que eu adicionei antes e trocar por (nome mais claro + endpoint corrigido):

```ts
type CheckoutStatus = "PENDING" | "PAID" | "CANCELLED" | "EXPIRED" | "REFUNDED" | string;

export async function fetchAbacateCheckoutStatus(billId: string): Promise<{ status: CheckoutStatus; metadata?: Record<string, unknown> } | null> {
  const apiKey = process.env.ABACATEPAY_API_KEY;
  if (!apiKey || !billId) return null;
  try {
    const response = await fetch(`${ABACATEPAY_BASE_URL}/checkouts/get?id=${encodeURIComponent(billId)}`, {
      headers: { Authorization: `Bearer ${apiKey}` },
    });
    const json = await response.json();
    if (!response.ok || !json?.success) return null;
    return { status: json.data?.status as CheckoutStatus, metadata: json.data?.metadata };
  } catch {
    return null;
  }
}
```

# Prompt 39 — Quiz: cortar opções sem quebrar o diagnóstico

Mexa em dois arquivos:
- `artifacts/perguntas-de-conexao/src/pages/Lp3.tsx` (array `quizQuestions`)
- `artifacts/perguntas-de-conexao/src/lib/lp3-narrative.ts` (só remover
  condições que ficaram órfãs)

Nada mais.

## Por que

Nas gravações, duas perguntas travam as pessoas. São exatamente as duas com
mais opções:

| # | Pergunta | Opções hoje | Vira |
|---|---|---|---|
| 1 | tempo juntos | 5 | 4 |
| 2 | **rotina** | **6** ← trava | 4 |
| 3 | curiosidade | 5 | 4 |
| 4 | vulnerabilidade | 4 | 4 (não muda) |
| 5 | **desejo** | **7** ← trava mais | 5 |

A de 7 é a **última** do quiz: a pessoa chega no fim e recebe a lista mais
longa da página inteira.

## A regra que eu segui, e por que importa

`lib/lp3-narrative.ts` decide o diagnóstico comparando as respostas **por texto
exato** (`answers.desire === "Reacender a intimidade"`). Se um texto muda, a
comparação vira letra morta e o diagnóstico sai errado **sem dar erro nenhum**.

Por isso: **nenhum texto de opção que fica foi reescrito.** Só apaguei opções
inteiras. As que ficam estão idênticas, caractere por caractere. Se você
reescrever alguma delas, tem que caçar a comparação correspondente no
`lp3-narrative.ts` — e é aí que quebra.

## lp3-narrative.ts — limpar as condições órfãs

Duas opções deixaram de existir. As comparações que apontam para elas viram
código morto. Não quebram nada, mas some com elas para o arquivo não mentir:

**1.** Por volta da linha 316, tire a menção a "Tentamos fazer algo diferente":

```ts
  if (
    lowDiscovery
    && answers.routine === "Conversamos bastante"
  ) {
    return "discovery";
  }
```

**2.** Por volta da linha 325, tire "Nos últimos dias" e "Tentamos fazer algo
diferente":

```ts
  if (
    answers.vulnerability === "Acho que não"
    && answers.curiosity === "Hoje"
    && answers.routine === "Conversamos bastante"
  ) {
    return "healthy";
  }
```

**Não mexa em mais nada** nesse arquivo. As outras comparações continuam
válidas porque os textos delas não mudaram.

## Depois de aplicar

1. `pnpm run build` tem que passar.
2. **Antes do deploy**, faça o quiz **cinco vezes**, uma para cada opção da
   pergunta 5, e anote qual diagnóstico saiu. O esperado:
   - "Ter mais assunto mesmo à distância" → diagnóstico de distância
   - "Reacender a intimidade" → diagnóstico de intimidade
   - "Conversar sobre coisas difíceis" → "existe uma conversa esperando"
   - "Voltar a sentir mais proximidade" → reconexão (ou rotina, se você
     respondeu celular/rotina e baixa descoberta antes)
   - "Ter conversas mais profundas" → depende das outras respostas
3. Se **duas ou mais** dessas cinco caírem no mesmo diagnóstico genérico,
   alguma comparação ficou órfã. Me avise antes de fazer deploy.
4. Deploy.

# Prompt 65 — Uma linha só

Do 64, **três dos quatro consertos entraram.** Falta um, e é o mesmo de antes:
a frase do tempo continua invisível no card claro.

---

## O problema

```
.lp-price-time   color: rgb(249, 248, 251)
card             background: rgb(251, 249, 255)
```

Diferença de luminância: **1,6 de 255.** É branco no branco.

A regra do 64 (`.lp1-price-card .lp-price-time { color: #241d33 }`) **não está
ganhando** — existe outra regra no `index.css` com especificidade maior mirando
`.lp-price-time`. Testei ao vivo: com `!important` a cor entra na hora.

## O conserto

**Primeiro tente achar a regra que está ganhando.** Procure no `index.css` por
`lp-price-time` — deve haver uma regra com prefixo grande (do tipo
`.lp-main:has(.lp2-hero) …` ou `.lp-price-card …`) definindo `color`. Se achar,
**troque a cor lá** e pronto, sem `!important`.

Se não achar em 2 minutos, resolva assim e siga em frente:

```css
.lp1-price-card .lp-price-time {
  color: #241d33 !important;
  font-weight: 500;
}
```

É a única `!important` que eu peço na página. Vale porque essa frase é a regra
mais forte de todos os treze guias — **Pricing p.50 (Mogilner & Aaker 2009)**:
a placa que falava de *tempo* atraiu **o dobro** de gente, e essas pagaram **o
dobro**.

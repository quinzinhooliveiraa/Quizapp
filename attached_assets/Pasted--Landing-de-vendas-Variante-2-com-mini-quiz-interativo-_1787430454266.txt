**Objetivo:** criar uma SEGUNDA versão da landing, num ângulo diferente da v1 (que já está em `/`): em vez de tudo estático (scroll e lê), essa versão coloca um **mini-quiz de 3 perguntas** antes de mostrar o preço — a pessoa responde "vocês estão namorando/casados", "que fase", "o que mais chama agora" e recebe 3 perguntas de exemplo PERSONALIZADAS pro perfil dela, aí sim vê o preço. ## 1. Transformar `Home` para aceitar uma variante — `artifacts/perguntas-de-conexao/src/App.tsx`

Achar `function Home() {` (linha ~446). Mudar a assinatura para aceitar uma prop `variant`:

```tsx
function Home({ variant = 'v1' }: { variant?: 'v1' | 'v2' }) {
```

Todo o resto do corpo de `Home` (states, `checkout()`, `useEffect`s de polling, etc.) **continua exatamente igual, sem mudar nada** — só a parte de JSX do `return` que hoje renderiza a landing (hero → footer) vai virar condicional.

Achar o `return (...)` de `Home` e localizar onde começa a landing JSX (a `<section className="lp-hero">` ou similar que veio dos prompts anteriores, ou a antiga `<section className="hero">` se ainda não tiver aplicado a v1).

Envolver a landing (tudo que é conteúdo de marketing — do nav/hero até o footer, ANTES do checkout modal) assim:

```tsx
{variant === 'v1' ? (
  <LandingV1 onBuy={() => { setSelectedPackage('couple'); setCheckoutState('idle'); setCheckoutOpen(true); }} />
) : (
  <LandingV2Quiz onBuy={() => { setSelectedPackage('couple'); setCheckoutState('idle'); setCheckoutOpen(true); }} />

```

Depois disso, ainda dentro do mesmo `return`, o checkout modal (`{checkoutOpen && <div className="modal-backdrop">...`) continua exatamente como está, fora do `if/else` — os dois variants usam o MESMO modal de checkout.

**Extrair a landing atual (v1) pra uma função separada** `LandingV1` (definida no topo do arquivo, fora de `Home`), recebendo `onBuy: () => void` como prop, e trocando todo `onClick={() => { setSelectedPackage('couple'); setCheckoutState('idle'); setCheckoutOpen(true); }}` dentro dela por `onClick={onBuy}`. É literalmente pegar o JSX que já existe (hero, dor, solução, temas, prova social, preço, faq, cta final, footer da v1) e mover pra dentro dessa função nova, sem mudar o conteúdo.

## 3. Adicionar `LandingQuizWidget` — mesmo arquivo, junto com `LandingV2Quiz`

```tsx
function LandingQuizWidget({ onFinish }: { onFinish: () => void }) {
  const [step, setStep] = useState(0);
  const [theme, setTheme] = useState<'porto' | 'faisca' | 'livro'>('porto');

  const PREVIEWS: Record<string, { title: string; questions: string[] }> = {
    porto: {
      title: 'Porto Seguro',
      questions: [
        'Qual foi a última vez que você se sentiu completamente em casa comigo?',
        'O que eu faço, sem perceber, que te faz respirar mais fundo?',
        'Se um dia esta versão nossa acabasse, do que você mais sentiria falta?',
      ],
    },
    faisca: {
      title: 'Faísca',
      questions: [
        'O que em mim ainda te surpreende — que você não esperava?',
        'Quando foi a última vez que você me olhou e pensou "quero de novo"?',
        'Qual gesto meu, mesmo bobo, te desarma na hora?',
      ],
    },
    livro: {
      title: 'Livro Aberto',
      questions: [
        'Qual medo você tem sobre nós que ainda não me disse?',
        'O que você acha que eu deveria saber sobre você e nunca perguntei?',
        'Existe algo que você mudaria na gente hoje, se pudesse?',
      ],
    },
  };

  if (step === 3) {
    const preview = PREVIEWS[theme];
    return (
      <div className="lp-quiz-result">
        <p className="lp-quiz-pill">Seu baralho ideal pra começar:</p>
        <h3 className="lp-quiz-result-title">{preview.title}</h3>
        <div className="lp-quiz-cards">
          {preview.questions.map((q, i) => (
            <div key={i} className="lp-quiz-preview-card">
              <span className="lp-mock-tag">{preview.title.toLowerCase()}</span>
              <p>"{q}"</p>
              <span>{String(i + 1).padStart(2, '0')} / 31+</span>
            </div>
          ))}
        </div>
        <p className="lp-quiz-cta-text">
          <strong>Essas são só 3 de 445+.</strong> Desbloqueie o baralho completo e os outros 14 temas:
        </p>
        <button onClick={onFinish} className="lp-cta-primary lp-cta-big" data-testid="button-quiz-cta-v2">
          Quero ver o preço <ArrowRight size={18} />
        </button>
      </div>
    );
  }

  const steps = [
    { key: 'role', label: 'Vocês estão:', options: ['Namorando', 'Casados', 'Relação longa'] },
    { key: 'phase', label: 'Como você descreveria a fase de vocês?', options: ['Início, descobrindo', 'Anos juntos, rotina', 'Precisamos reconectar'] },
    { key: 'theme', label: 'O que mais te chama agora?', options: [{ l: 'Aquecer, sem susto', v: 'porto' }, { l: 'Provocar, apimentar', v: 'faisca' }, { l: 'Ir fundo de verdade', v: 'livro' }] },
  ];
  const current = steps[step];

  return (
    <div className="lp-quiz">
      <div className="lp-quiz-progress">
        <span className={step >= 0 ? 'is-active' : ''} />
        <span className={step >= 1 ? 'is-active' : ''} />
        <span className={step >= 2 ? 'is-active' : ''} />
      </div>
      <p className="lp-quiz-question">{current.label}</p>
      <div className="lp-quiz-options">
        {current.options.map((opt) => {
          const label = typeof opt === 'string' ? opt : opt.l;
          const value = typeof opt === 'string' ? opt : opt.v;
          return (
            <button
              key={label}
              onClick={() => {
                if (current.key === 'theme') setTheme(value as typeof theme);
                setStep(step + 1);
              }}
              className="lp-quiz-option"
              data-testid={`button-quiz-${current.key}-${label}`}
            >
              {label}
            </button>
          );
        })}
      </div>
    </div>
  );
}
```

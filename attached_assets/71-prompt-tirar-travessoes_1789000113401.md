# Prompt 71 — tirar os travessões "de IA" da copy

Cole no Replit. Só troca de texto, nenhuma outra mudança.

## O que é

Tirar os travessões (—) usados como **conector no meio da frase** — é o padrão
que faz o texto parecer escrito por IA. Cada troca abaixo mantém o sentido, só
muda a pontuação (vira ponto, vírgula ou dois-pontos).

**IMPORTANTE:** troque **exatamente** as linhas abaixo. Não saia trocando todo
"—" da base de código no automático — tem um caso que FICA (o diálogo), listado
no fim.

## As trocas (de → para)

**Hero (subtítulo):**
```
DE:   Você quer a conversa. Ele responde "sei lá" — e morre ali.
PARA: Você quer a conversa. Ele responde "sei lá". E morre ali.
```

**Hero (link secundário):**
```
DE:   Já sei o que quero — comprar agora →
PARA: Já sei o que quero: comprar agora →
```

**Hero e fecho (linha de confiança) — as duas ocorrências:**
```
DE:   🔒 Pix e cartão · 7 dias de garantia — não gostou, devolvo. Você decide.
PARA: 🔒 Pix e cartão · 7 dias de garantia. Não gostou, devolvo. Você decide.
```

**Seção "sei lá" (lede):**
```
DE:   É o medo de todo mundo — e é por isso que o baralho começa leve.
PARA: É o medo de todo mundo. É por isso que o baralho começa leve.
```

**Proposta (lede):**
```
DE:   ...tirar a conversa do automático — sem clichê, sem "qual seu animal favorito".
PARA: ...tirar a conversa do automático, sem clichê, sem "qual seu animal favorito".
```

**Garantia:**
```
DE:   Sem drama, sem perguntas — e você decide.
PARA: Sem drama, sem perguntas. E você decide.
```

**FAQ "terapia de casal":**
```
DE:   É um empurrão pra vocês conversarem sozinhos — não substitui acompanhamento se a relação precisa.
PARA: É um empurrão pra vocês conversarem sozinhos. Não substitui acompanhamento se a relação precisa.
```

**FAQ "vamos conversar":**
```
DE:   Porque "vamos conversar" trava — ninguém sabe por onde começar.
PARA: Porque "vamos conversar" trava: ninguém sabe por onde começar.
```

**FAQ "parceiro achar estranho":**
```
DE:   Por isso os baralhos começam leves — você escolhe o clima.
PARA: Por isso os baralhos começam leves: você escolhe o clima.
```

**FAQ "vitalício":**
```
DE:   Paga uma vez, usa pra sempre — incluindo os baralhos novos que entram depois.
PARA: Paga uma vez, usa pra sempre, incluindo os baralhos novos que entram depois.
```

**FAQ "como recebo":**
```
DE:   ...assim que a confirmação chega — o Pix cai na hora.
PARA: ...assim que a confirmação chega. O Pix cai na hora.
```

**FAQ "por que R$ 47,90":**
```
DE:   Você paga uma vez e fica com tudo — dá 10 centavos por pergunta.
PARA: Você paga uma vez e fica com tudo. Dá 10 centavos por pergunta.
```

## O que FICA (não troque)

**A tabela comparativa — o diálogo:**
```
"E aí, como foi o dia?" — "Normal."
```
Esse travessão é **diálogo em português** (travessão de fala), não vício de IA.
Trocar aqui deixaria estranho. Se você quiser mesmo tirar por gosto, a única
troca aceitável é fechar as falas em linhas separadas, mas o recomendado é
**deixar como está**.

## Confira depois

- Nenhuma frase do site tem mais "—" no meio, exceto o diálogo da tabela.
- Nenhum sentido mudou; só a pontuação.
- Se sobrar algum "—" em texto que não está nesta lista (quiz, diagnóstico),
  aplica a mesma regra: vira ponto, vírgula ou dois-pontos, e me avisa quais
  eram pra eu conferir.

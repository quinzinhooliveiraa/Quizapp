**Isso substitui o prompt anterior** (`logo-final-icone-splash-replit.md`, que ia com arquivos já recortados por mim). Desta vez, **você mesmo vai anexar as duas imagens originais** (sem corte) direto neste chat, e o Replit Agent cuida do recorte/posicionamento.

**IMPORTANTE: anexe as 2 imagens originais junto com este prompt:**
1. **A imagem nítida** (fundo vinho/roxo escuro, as três cartas com "PERGUNTAS DE CONEXÃO" e as mãos com o fio virando coração) — essa é **a logo**.
2. **A imagem só com os traços, brilhando/desfocada no fundo preto** — essa é pra **tela de entrada** (o efeito de "entrando em foco").

O Replit Agent salva as duas em `attached_assets/` automaticamente. Renomeie (ou ajuste os imports abaixo pro nome real que ficou salvo):
- `attached_assets/logo-nitida.png` (a primeira, nítida)
- `attached_assets/logo-glow.png` (a segunda, desfocada/brilhando)

**IMPORTANTE: aplicar direto nos arquivos. As 2 imagens SIM devem virar asset — o restante da instrução é pra aplicar direto no código.**

## 1. Ícones do PWA e favicon — precisam de um recorte quadrado, sem o texto

Diferente da splash (que pode usar a imagem inteira com CSS, ver seção 3), os ícones do sistema (`manifest.json`, favicon, apple-touch-icon) **precisam ser arquivos de imagem quadrados prontos** — não dá pra recortar só com CSS porque o navegador/celular lê o arquivo direto.

**Peça pro Replit Agent gerar esses recortes a partir de `logo-nitida.png`** (ele consegue processar imagem via código, não precisa de nenhuma ferramenta externa):

- Recortar um quadrado centralizado na região das duas mãos + o coração de fio (a faixa do meio da carta), **excluindo** o título "PERGUNTAS DE CONEXÃO" (topo) e o monograma pequeno (rodapé) — só o desenho das mãos e do coração.
- Gerar esse recorte quadrado em 3 tamanhos: 512×512 (`public/icons/icon-512.png`), 192×192 (`public/icons/icon-192.png`), 180×180 (`public/apple-touch-icon.png`).
- Pra esses 3, aplicar cantos arredondados (raio de ~22% do tamanho) com fundo preenchido na cor de fundo da própria carta (vinho escuro), sem ficar transparente nas bordas.
- Pra `public/favicon.png` (32×32), fazer um recorte ainda mais fechado, só do coraçãozinho de fio (sem as mãos) — em 32px as mãos viram borrão, mas o coração sozinho continua legível.

Apagar os arquivos antigos `icon-192.svg`, `icon-512.svg` e `favicon.svg` (o quadrado laranja genérico que está lá hoje) depois de colocar os novos `.png` no lugar.

## 4. Animação de entrada — usando as imagens inteiras, recorte só com CSS

Aqui **não precisa recortar o arquivo** — as duas imagens (`logo-glow.png` e `logo-nitida.png`) entram inteiras, e o CSS mostra só a região central (as mãos + coração) usando `object-fit` e `object-position`, cortando visualmente o título e o monograma sem precisar editar o arquivo.

### 4a. Componente — novo arquivo `artifacts/perguntas-de-conexao/src/components/splash-screen.tsx`

```tsx
import { useEffect, useState } from 'react';
import splashGlow from '@assets/logo-glow.png';
import splashSharp from '@assets/logo-nitida.png';

export function SplashScreen() {
  const [visible, setVisible] = useState(true);
  const [focused, setFocused] = useState(false);
  const [fading, setFading] = useState(false);

  useEffect(() => {
    const focusTimer = window.setTimeout(() => setFocused(true), 250);
    const fadeTimer = window.setTimeout(() => setFading(true), 1300);
    const removeTimer = window.setTimeout(() => setVisible(false), 1700);
    return () => {
      window.clearTimeout(focusTimer);
      window.clearTimeout(fadeTimer);
      window.clearTimeout(removeTimer);
    };
  }, []);

  if (!visible) return null;

  return (
    <div className={`app-splash${fading ? ' app-splash-fade' : ''}`}>
      <div className="app-splash-stage">
        <img src={splashGlow} alt="" className="app-splash-glow" />
        <img
          src={splashSharp}
          alt=""
          className={`app-splash-sharp${focused ? ' app-splash-sharp-focused' : ''}`}
        />
      </div>
    </div>
  );
}
```

Nota: o import usa `@assets`, o alias que o projeto já tem pra pasta `attached_assets/` (confirme no `vite.config.ts` se o alias tem outro nome).

### 4b. CSS — adicionar no final de `artifacts/perguntas-de-conexao/src/index.css`

```css
.app-splash {
  position: fixed;
  inset: 0;
  z-index: 9999;
  display: flex;
  align-items: center;
  justify-content: center;
  background: #17121b;
  opacity: 1;
  transition: opacity 0.45s ease;
  overflow: hidden;
}
.app-splash-fade {
  opacity: 0;
  pointer-events: none;
}
.app-splash-stage {
  position: relative;
  width: min(70vw, 340px);
  aspect-ratio: 1 / 1;
  border-radius: 28px;
  overflow: hidden;
}
.app-splash-glow,
.app-splash-sharp {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  /* object-fit + object-position fazem o recorte visual: mostra só a região
     central da imagem (mãos + coração), sem precisar de um arquivo já cortado */
  object-fit: cover;
  object-position: 50% 50%;
}
.app-splash-glow {
  opacity: 1;
  transform: scale(1.08);
  animation: app-splash-pulse 1.6s ease-in-out infinite;
}
.app-splash-sharp {
  opacity: 0;
  filter: blur(14px);
  transform: scale(0.94);
  transition: opacity 0.55s ease, filter 0.55s ease, transform 0.55s ease;
}
.app-splash-sharp-focused {
  opacity: 1;
  filter: blur(0);
  transform: scale(1);
}
@keyframes app-splash-pulse {
  0%, 100% { opacity: 0.75; transform: scale(1.05); }
  50% { opacity: 1; transform: scale(1.12); }
}
```

**Ajuste fino do recorte:** o `object-position: 50% 50%` centraliza a imagem inteira dentro do quadrado, o que deve deixar a faixa das mãos+coração bem posicionada (ela já fica perto do centro vertical nas duas imagens). Depois de aplicar, abrir o app e conferir — se a faixa das mãos ficar cortada de um jeito estranho (por exemplo mostrando mais o título do que as mãos), ajustar o `object-position` pra `50% 55%` ou `50% 60%` (empurra o "foco" do corte pra baixo, onde estão as mãos) até ficar enquadrado corretamente.

### 4c. Usar o componente — `artifacts/perguntas-de-conexao/src/App.tsx`

Importar no topo:
```tsx
import { SplashScreen } from '@/components/splash-screen';
```

Achar a função `App` e adicionar `<SplashScreen />` dentro do `<TooltipProvider>`, junto com o `<Toaster />`:

```tsx
function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <TooltipProvider>
        <WouterRouter base={import.meta.env.BASE_URL.replace(/\/$/, '')}>
          <Router />
        </WouterRouter>
        <Toaster />
        <SplashScreen />
      </TooltipProvider>
    </QueryClientProvider>
  );
}
```

## Verificação

1. Recarregar o app do zero → o brilho desfocado aparece pulsando, a versão nítida entra em foco por cima (mostrando as mãos + coração, sem cortar de forma estranha), depois some revelando o app.
2. Se o enquadramento da splash estiver errado (mostrando texto ou parte de outra carta em vez das mãos), ajustar o `object-position` como descrito na seção 4b.
3. Testar em mobile e desktop.
4. Aba do navegador → favicon novo (coraçãozinho, tom vinho), sem o texto (ilegível em 32px de qualquer forma).
5. No celular, "Adicionar à tela inicial" → confirmar que o ícone mostra as mãos + coração centralizados, sem cortar de forma estranha nem mostrar o texto cortado ao meio.
